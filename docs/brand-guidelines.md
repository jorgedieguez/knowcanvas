# Identidad de KnowCanvas

## Idea central

KnowCanvas convierte conocimiento estructurado en experiencias visuales e interactivas. La identidad combina confianza tecnológica, creatividad y aprendizaje sin infantilizar el producto.

## Logotipo

- Archivo maestro para producto web: `/public/brand/logo_knowcanvas_primary_20261101_horizontal.png`.
- La composición horizontal completa es la variante principal para acceso, biblioteca, cabeceras y páginas legales.
- En espacios de menos de 120 px se muestra únicamente el símbolo mediante una ventana de recorte sobre el mismo archivo; no se redibuja ni recolorea.
- Debe conservarse la proporción original, el fondo transparente y una zona libre equivalente, como mínimo, a la mitad de la altura visible del símbolo.
- No se aplican sombras, bordes, rotaciones ni gradientes adicionales al logotipo.

## Paleta

| Token  | Color     | Uso                                                  |
| ------ | --------- | ---------------------------------------------------- |
| Navy   | `#08152F` | Texto principal y contraste institucional            |
| Blue   | `#0878ED` | Acción primaria, foco, selección y enlaces           |
| Violet | `#6B35D5` | IA, creatividad y acentos secundarios                |
| Yellow | `#F7B733` | Énfasis educativo puntual y advertencias no críticas |
| Green  | `#39A965` | Confirmación, conexión y progreso                    |
| Canvas | `#F5F7FB` | Fondo general de la aplicación                       |

Los fondos y superficies siguen siendo neutros. Azul y violeta no deben competir simultáneamente como acciones principales. Amarillo y verde se reservan para estados y pequeños acentos.

## Tipografía

La interfaz utiliza la pila nativa del sistema (`SF Pro`, `Segoe UI`, Inter como fallback). Se favorecen pesos 550–700 para títulos y 400–500 para contenido. La marca del logotipo nunca se recompone con texto HTML visible.

## Voz

- Clara, directa y orientada a la creación.
- Profesional, cercana y pedagógica.
- Se habla de libros, páginas, lienzos y experiencias; “proyecto” queda como término técnico interno.
- Propuesta breve: **Conocimiento que cobra vida.**

## Accesibilidad

- Texto normal: contraste mínimo 4.5:1.
- Controles, foco y bordes significativos: contraste mínimo 3:1.
- El logotipo completo tiene alternativa `KnowCanvas`; las apariciones decorativas del símbolo se ocultan al árbol de accesibilidad.
